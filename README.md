# حصون — تنظيم حفظ القرآن الكريم

حصون تطبيق ويب تقدمي (PWA) عربي RTL يساعد على حفظ القرآن الكريم ومراجعته بطريقة **الحصون الخمسة**، وفق تقسيم المصاحف المغاربية ورواية ورش عن نافع.

## الحالة الحالية

- 480 ثمنًا: 60 حزبًا × 8 أثمان.
- خطة يومية مؤرخة ومستقلة عن محطة الحفظ.
- حصون التلاوة، الاستماع، التحضير، الحفظ الجديد، ومراجعة القريب والبعيد.
- جلسات مؤقتة للحفظ والتحضير والمراجعة والتثبيت.
- قارئ مصحف مناسب للهاتف مع تقليب أفقي وصوت مشترك.
- تخزين محلي أولًا، نسخ احتياطية واسترجاع، ومزامنة اختيارية مع Supabase.
- خريطة أحزاب، مراحل، شارات، تقويم نشاط، ونقاط XP مع تأثير بصري عند إتمام المهمة.
- ثيمات: دافئ، فاتح، داكن، محيطي، ومحيطي داكن.
- لا توجد أداة لتعديل أو اقتراح تصحيح نصوص الأثمان؛ بيانات القرآن ثابتة داخل التطبيق.

## التشغيل

المتطلبات: Node.js 22 أو أحدث وnpm.

```bash
npm ci
npm run dev
```

افتح `http://localhost:3000`.

## أوامر الجودة

```bash
npm run type-check
npm run lint
npm test
npm run test:e2e
npm run verify-data
npm run verify-offline
npm run build
```

## المزامنة السحابية الاختيارية

انسخ `.env.local.example` إلى `.env.local` وأضف:

```text
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

يعمل التطبيق محليًا دون هذه المتغيرات. لتجربة قاعدة البيانات محليًا:

```bash
npx supabase start
npx supabase db reset --local
npx supabase test db
```

## البنية

```text
src/app/                 صفحات Next.js وملف CSS العام
src/components/          الواجهة، التبويبات، القارئ، الجلسات، والصوت
src/store/               الحالة الدائمة، الجلسات، الصوت، وXP
src/lib/progress/        التحقق، الترحيل، الدمج، النسخ الاحتياطي، والمزامنة
data/                    بيانات الأثمان والأحزاب ومصادرها
quran/                   فهارس السور وإعدادات البيانات
scripts/                 توليد البيانات والتحقق منها
supabase/                المخطط والترحيلات واختبارات RLS
tests/e2e/               اختبارات Playwright للمتصفح
```
