# المصادر وحدودها

## القرآن والمصحف

- بيانات الحدود: `src/lib/quran-thumuns.json`، وعداد سور مغاربي `quran-surahs.json` (114 سورة، 6214 آية وفق هذا المصدر)، والمطالع `quran-incipits.json`. أصل التوليد موثق في README و`data/upstream/SOURCES.md`.
- أُبقيت هذه الملفات دون تعديل. `getThumun` لا يدمج المسودات، والصفوف مصونة أيضًا بـ`Object.freeze` وقت التشغيل. التطبيع للبحث فقط، لا للنص المعتمد.
- الصور: `public/mushaf/pages/page1.jpg` إلى `page485.jpg`؛ ترقيم مصحف الأثمان مستقل عن ترقيم صفحات مصدر الحدود. صفحة الغلاف 0 لا تدخل نطاق القراءة/التنزيل.
- الصفحات 480/481/483 مشتركة. العنوان والمشغل بحسب الثمن المحدد، مع ذكر الاشتراك صراحة. لا تنسب حدود ثمن آخر إلى الصورة بصمت.
- `public/mushaf/catalog.json`: SHA-256 وحجم كل صورة موجودة، يولّد بـ`npm run generate-mushaf-catalog`. المصحف 76,208,542 bytes للأوراق 1..485. `verify-offline` يقارن كل byte/hash. هذا تحقق تقني لا توثيق ديني للطبعة.

## الصوت

مصدر الروابط الحقيقي هو `src/lib/quran-audio.ts` و`getHizbAudioUrl`/`getThumunAudioUrl`، وليس قائمة أسماء افتراضية فقط. أحزاب الحصري/ورش وغيرها من اختيارات الحزم، وتسجيلات الأثمان من أرشيفات المزودين المذكورة في هذا الملف. `quran-audio.test.ts` يتحقق من نمط الروابط والأرقام والاشتراك، ولا يتظاهر بأنه تحقق من كل تسجيل.

مشغل واحد/HTMLAudioElement واحد وMediaSession واحدة. الانتقال إلى مادة أخرى يوقف المسار السابق عند التشغيل، وتغيير الثمن في القارئ يوقف صوت ثمن مختلف. مصدر التسجيل خارجي؛ فشل الشبكة/codec واضح وإعادة المحاولة متاحة. A/B حلقة مقطع فعلية، وليست شهادة إنجاز للورد.

## المراجعة والسجل

الورد التقويمي مستقل. قراءة/استماع متتابعان بحسب الوتيرة، وتحضير المواد القادمة غير المحفوظة. القريب يتبع ترتيب 8،2،4،6،1،3،5،7 ضمن المخزون المتاح، والبعيد يتقدم بنافذة 16/24/32 ثم يعود عند نهاية المخزون الموثق. المواد والإزاحة تُحفظ في الخطة ولا يعاد تفسيرها بتغيير الإعدادات.

تحديد سور غير متصلة حالة تستلزم مواءمة منهجية عند المراجع؛ لا يُقدَّم غير المحفوظ كأنه محفوظ. الاقتراحات الحرة بحسب آخر تقييم/محاولة وتاريخها قابلة للتفسير، ولا تغير المراجعة المخططة تلقائيًا. مدة الختمة تقديرية؛ 480 محطة ليست 480 يومًا حتميًا.

التعديلات الشخصية السابقة محفوظة كمسودات مع الرصيد/الملاحظات في ترحيل v3؛ التصحيح الجديد يحتاج سببًا ومصدرًا وتحقق ترتيب/عدد آيات، ثم مراجعة مخوّلة. إرسال اقتراح لا يعدّل مصدر القراءة.
