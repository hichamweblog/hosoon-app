## نتائج منفذة في البيئة المحلية

- **155 اختبار وحدة ناجحًا / 11 ملفات**: الإتمام والختمة والفجوات، اليوم 1/2/9/10/479/480، المعاينة، التثبيت، namespace/rollback، schema/prototype pollution، tombstones، commutative/associative/idempotent merge، CAS/read-failure/idle loops، وحذف الحساب.
- **24 اختبار Playwright ناجحًا**: ورد/تهيئة، nested Back/Escape/focus وتوقيت الجلسة، استيراد صالح/فاسد، عزل A/B ونقل الضيف/reset/recovery **بخادم محاكى**، وMediaSession/صوت واحد **بـWAV fixtures**.
- axe للمنزل والإحصائيات والإعدادات والحساب في **الثيمات الخمسة**، والجلسة والقارئ: **لا مخالفات critical/serious في نطاق الفحص الآلي**. تحقق keyboard و200% و320/390/landscape داخل المتصفح الآلي؛ لا ادعاء فحص قارئ شاشة بشري أو هاتف فعلي.
- **24 تحقق PostgreSQL 17.5 محلي (WASM)** ناجحًا: تنفيذ الترحيلين، عزل الصفوف/الاقتراحات/الرجوع، CAS وnull guards وepoch وعدم الإحياء، الحدود الفعلية وترتيب الآيات، cascade. auth claims synthetic في هذا الاختبار؛ ليس Supabase حيًا.
- `npm ci` وtype-check وlint وفحص بيانات القرآن والبناء ناجحة. `npm audit`: **0 تنبيهات معروفة** عند الفحص، مقارنة بـ11 قبل التنفيذ؛ ليس ضمانًا ضد ثغرات غير معروفة.
- 480 ثمنًا و114 سورة و6214 آية وفق مصدر المشروع، **دون تغيير JSON المعتمد**. تحقق SHA-256 لـ485 صورة.
- **61 عنصر precache للهيكل، 0 صور مصحف تلقائية** في البناء المفحوص. نجح cold opening لصفحة جديدة دون اتصال مع العلامة والملاحظة والصورة المنزلة. المصحف الكامل لا ينزل إلا بالاختيار.

## أمثلة الحساب بعد الإصلاح

- أول ورد: 4 مهام، 85 نقطة مهام + 25 مكافأة = **110**؛ يوم مؤرخ واحد مكتمل وثمن واحد محفوظ.
- ثمنان مكتسبان على جهازين: **100** نقطة للحفظ عند الدمج، لا `max(50,50)`.
- قراءة/سماع في محطة 16 لا يصنع جزءًا محفوظًا. كل جزء/حزب يحتاج جميع أثمانه، والزهراوان تحتاج كل الوحدات حتى 60 دون فجوات.
- أول 60 ثمنًا محفوظًا سابقًا: **0** أيام ورد مختلقة، **0** XP جديد، لا سلسلة مصنوعة بالتهيئة.
- المحطة 480 لا تعلن ختمة مع فجوة. التثبيت الجديد ينشئ خطة جديدة وتلاوة دورة جديدة دون محو الرحلة.

## ما لم يُنفذ على جهة حيّة

لم تُطبق SQL على إنتاج، ولم تُحذف حسابات حقيقية، ولم تُرسل إشعارات Push. لم تُختبر ملفات التسجيل الخارجي كلها أو تراخيص/صحة كل طبعة دينيًا. لم ينفذ workflow على GitHub ضمن هذه الجلسة، ولا نشر/rollout على هواتف حقيقية.

قبل الإنتاج: بوابة staging بحسابين وJWT حقيقيين، مزود البريد/recovery، admin deletion، quota/offline على iOS وAndroid، ومراجعة مختص. التفاصيل وخطة التراجع موجودة في **`DEPLOYMENT_AR.md`** و**`DATA_AND_MEDIA_AR.md`**.
